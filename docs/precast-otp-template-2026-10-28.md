# 추가 문자 인증 전용 템플릿

> 후속: 2026-10-29 사용자 요청으로 발송 활성화·배포를 완료했다. 최신 상태는 [문자 발송 과금 기록](sms-dispatch-2026-10-29.md)을 따른다. 아래 비활성 상태는 준비 당시의 기록이다.

사용자 요청으로 2026-10-28 운영 문자 서버에 등록했다. 실제 문자 발송·서비스 재시작·코드 배포는 하지 않았다.

## 등록 내용

- 앱: `openvote` / 모아이투표
- 이름: `moai_precast_otp_v1`
- ID: `tpl_84793e9a8c31`
- 채널: SMS
- 호출 변숫값: `code` 하나. 서버가 만드는 6자리 숫자를 넣는다.
- EUC-KR 기준 65바이트: SMS 90바이트 한도 이내.

```text
[모아이투표] 인증번호 {code} (5분 유효)
타인에게 알려주지 마세요.
```

선거 이름·전화번호·참여 링크·투표 자격·기표 내용은 본문에 넣지 않는다. 5분 유효 표기는 `audit_otp_issue`의 실제 유효기간과 같다. 기존 투표안내 템플릿은 수정하지 않았다.

## 적용·검증

- 기존 notifier 관리 함수로 전용 템플릿 행만 추가했다. 다른 앱·템플릿·프로바이더 설정은 변경하지 않았다. 서버 코드 변경·재배포가 필요하지 않다.
- `validate_notify_template`와 `render_notify`로 변수 목록·EUC-KR 인코딩·바이트 수를 확인했다. 운영 CLI로 등록 후 다시 조회했다. 발송 API와 테스트 발송 API는 호출하지 않았다.
- Vercel `bjy-space/open-vote`의 Production에 `MOAI_OTP_TEMPLATE=moai_precast_otp_v1`을 등록했다. 환경변수는 다음 배포부터 적용된다.
- `MOAI_OTP_SEND_ENABLED=false`를 유지한다. 이번 요청은 템플릿 준비이며, 유료 발송 활성화·재배포는 하지 않았다. 실제 수신·과금은 미검증이다.

활성화 시 기존 서명키·문자 서버 인증 정보를 유지하고 `MOAI_OTP_SEND_ENABLED=true`로 설정한 뒤 운영 배포가 필요하다. 별도 시험 문자 발송은 사용자 승인 없이 하지 않는다.
