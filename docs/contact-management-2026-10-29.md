# 연락처 선택 삭제·입력 영역 정리

## 동작

- 그룹 체크박스 및 그룹 전체 선택으로 선택 그룹을 함께 삭제한다. 그룹만 지우며 연락처는 보존한다.
- 연락처는 개별 체크박스, 현재 목록 전체 선택, 선택 연락처 삭제를 지원한다. 현재 그룹·검색 결과만 선택 대상으로 삼고 필터 변경 시 연락처 선택은 초기화한다.
- 그룹의 연락처를 전부 지우려면 그룹 선택 → 목록 전체 선택 → 선택 연락처 삭제로 처리한다. 연락처 삭제는 다른 그룹에서도 제거되며 기존 선거의 유권자 명부에는 영향을 주지 않는다.
- 삭제 직전 대상 수·범위·복구 불가를 확인한다. 200개씩 순차 처리하고 중간 실패 시 완료 수와 남은 선택을 보존한다.
- 연락처 추가·엑셀 가져오기 영역은 기본 접힘이다. 기존 연락처 수정을 누르면 자동으로 펼친다.
- 그룹 이름 변경·그룹 삭제는 연필·휴지통 아이콘으로 바꾸고 접근성 이름과 툴팁, 터치 영역을 제공한다.

- 기존 테스트 117개, ESLint, TypeScript, 프로덕션 빌드 통과.
