# 다모음 프런트 디자인 정리

기록일: 2026-10-26. 작업 위치: `open_vote`, 기존 `fix/vote-receipt-guidance` 브랜치의 미커밋 변경. 커밋·푸시·배포·DB 변경 없음.

## 디자인 방향

- 한글 본문에 Noto Sans KR을 적용한다. Next.js `next/font`가 빌드 때 내려받아 같은 사이트에서 제공하므로 방문자의 브라우저가 Google Fonts에 요청하지 않는다.
- 흰색 표면, 밝은 회청색 배경, 절제된 파란색 강조, 얇은 경계선과 충분한 여백을 공통으로 사용한다.
- 상단 메뉴는 투표 참여·진행 현황·결과·검증·이용 안내 순서로 배치하고 운영자 진입 버튼을 구분한다. 현재 메뉴를 표시하고, 하단에 안내·검증·운영자 링크를 제공한다. 포인트·회원 관리는 기존 관리 화면에서 접근한다.
- 홈은 서비스 소개와 주요 행동 → 바로가기 → 공개 선거 → 참여 방법 → 보안 안내 순서로 구성한다. 장식용 투표지 그림은 CSS와 기존 아이콘으로 구현하며 실제 투표지로 읽히지 않도록 보조기술에서 제외한다.
- 투표 목록·진행 현황·결과의 제목과 구분선을 통일한다. 진행 현황은 참여·전체·미참여를 중심으로 보여주고 중복 통계 카드를 제거하되 총 접수 표수는 안내줄에 유지한다.
- 생성 화면은 기본 정보·명부·기간·방식·항목을 번호와 구분선으로 묶는다. 기존 입력·처리·과금 로직을 유지한다.
- 버튼·필드·패널·상태 배지·빈 상태·진행 막대의 스타일을 통일한다. 본문 바로가기, 키보드 초점, 필드 도움말 연결, 진행 막대의 접근성 속성, 모션 감소 설정을 반영한다.

## 기존 작업 보존

작업 시작 전부터 수정되어 있던 `trust`, `verify`, 투표 완료 화면, 투표지, 영수증·검증 로직, ESLint 설정과 로그 파일은 직접 수정하지 않았다. 해당 화면에는 공통 폰트·외곽 레이아웃·UI 컴포넌트 스타일이 적용된다.

## 검증

- `npm run lint`: 통과. 마지막 UI 조정 후 변경한 TSX 전체에 대해 ESLint를 다시 실행해 통과했다.
- `npm test`: 기존 미커밋 작업을 포함한 74개 검사 모두 통과.
- 마지막 변경 후 `npm run build`: Next.js 16.2.6 프로덕션 빌드와 TypeScript 검사 통과.
- 변경 소스의 `git diff --check`: 통과.
- React Best Practices를 적용해 클라이언트 경계, effect 정리, 키, 의미 있는 링크·레이블, 상태 표시를 점검했다. 경로를 읽는 부분은 작은 `SiteNav` 클라이언트 컴포넌트로 분리하고 공통 프레임은 서버 컴포넌트로 유지한다.
- 로컬 프로덕션 서버에서 데스크톱 홈의 공개 선거 표시, 한글 폰트 실제 적용, 모바일 홈·투표 목록·진행 현황·결과의 메뉴 이동 및 현재 메뉴 표시, 운영자 로그인 폼을 확인했다. 모바일 390px 설정에서 측정한 문서 가로 넘침은 없었다. 브라우저의 스크롤바에 따라 실제 콘텐츠 너비는 375px 또는 390px이었다.
- 최종 홈 화면 브라우저 오류·경고 로그는 없었다. 공개 선거 목록 조회 외에 운영 DB 쓰기를 수행하지 않았다.
- 로그인 후 생성 화면의 실제 배치, 실제 휴대폰, 실제 투표 제출·문자 발송·포인트 차감은 이번에 검증하지 않았다. 생성 화면은 소스·린트·빌드로 확인했다.

## 후속 반영: 모아이투표 명칭과 첫 화면 간소화

사용자가 최종 명칭은 **모아이투표**라고 확인했다. 화면·메타데이터·서버의 사용자 안내 문자열과 README에 반영했다. 기존 미커밋 파일에서는 해당 명칭만 치환하고 나머지 변경을 보존했다. 위의 다모음 표기와 이전 홈 구성은 최초 작업 기록이다.

- 홈의 장식 그림·빠른 메뉴·참여 단계·긴 보안 안내를 제거했다. 기존 폰트·공통 디자인은 유지한다.
- 간단한 설명, 개인 투표 코드/링크 입력, 기술 확인·투표 생성 링크, 진행 중인 공개 투표와 검색창만 둔다.
- 목록은 기존 API의 `status=active` 조회와 클라이언트의 상태 필터를 사용한다. 검색은 가져온 공개 목록의 이름·설명에서 처리해 타이핑 중 추가 요청이 없다.
- 현재 시스템에는 짧은 숫자 참여 코드가 없다. 입력란은 기존 개인 토큰 또는 해당 링크 전체를 받는다. 형식을 검증한 뒤 같은 사이트의 `/v/<token>` 경로로만 이동하며 토큰의 실제 유효성은 기존 서버가 확인한다. 외부 주소·스크립트 URL·잘못된 입력은 차단한다. 입력값을 별도 로그나 저장소에 남기지 않는다.
- 사용하지 않는 홈 장식 스타일을 제거했다.
- `npm run lint`, `npm run build`, 테스트 **76/76**, `git diff --check` 통과. 브라우저에서 공개 투표 로딩, 검색 결과 없음·검색 초기화, 잘못된 코드 안내, 제목·로고 명칭 변경을 확인했다. 모바일 390px 설정에서 가로 넘침이 없고 브라우저 오류·경고가 없었다.
- 정상 코드·허용된 링크의 경로 변환과 위험한 입력 차단은 단위 테스트로 확인했다. 실제 유권자의 정상 코드로 투표 제출은 수행하지 않았다.
