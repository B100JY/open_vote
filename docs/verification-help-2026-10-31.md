# 검증 자료와 선택형 영수증 안내

- 기표 화면의 시작 규칙·현재 기준점 다운로드에 `검증용 자료 · 저장은 선택입니다` 안내와 설명 아이콘을 추가했다.
- 설명 아이콘은 `/trust/verification`을 새 탭에서 연다. 현재 기표 화면과 선택을 유지한다. 시작 규칙, 현재 기준점, 개인 영수증의 차이 및 마감 후 비교 흐름을 카드·아이콘으로 안내한다.
- 완료 화면은 영수증을 저장하지 않아도 투표가 정상 완료되었음을 먼저 표시한다. 저장 버튼은 보조 스타일과 `검증용 영수증 저장 (선택)`으로 변경했다.
- 파일 재발급 불가, 짧은 번호로 복구 불가, 타인 공유 주의는 유지하되 검증을 원하는 사람에게만 필요한 안내로 정리했다.
- 기표·영수증 생성·저장 형식·서명·검증 처리 로직 변경 없음. 운영 데이터·실제 문자 발송 없음.

## 관리자 완료 화면 미리보기

- `/admin/preview/vote-complete` 경로를 만들고 관리자 메뉴에 연결했다. 기존 `AdminGate adminOnly`로 관리자 역할 확인 후 표시한다.
- 실제 완료 화면을 `VoteCompleteScreen`으로 공유하여 안내와 UI가 함께 갱신되게 했다.
- 예시 영수증은 합성 값이며 미리보기임을 상단에 표시한다. 미리보기는 localStorage/sessionStorage를 읽거나 수정하지 않는다. 실제 투표·SMS·포인트 API 호출이 없고, 예시 영수증 저장·복사는 비활성화한다.
- 일반 `/vote/complete`의 기존 영수증 조회·저장 동작은 유지한다.

검증: 변경 파일 ESLint 및 프로덕션 빌드(TypeScript 포함) 통과. 사용자 요청에 따라 운영 배포 완료(`dpl_D9Sr3Xz22AXdhh7f8mAvkunkaAYm`, `https://open-vote-81yb7crit-bjy-space.vercel.app`, 운영 도메인 연결 완료). 운영 미리보기·완료·설명 페이지 HTTP 200, 제공 JS의 선택형 영수증 문구와 설명 페이지 내용을 확인했다. 로그인 후 실제 화면 조작은 별도로 수행하지 않았다. DB 변경·실제 문자 발송·커밋·푸시 없음.
