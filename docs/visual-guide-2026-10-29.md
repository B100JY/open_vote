# 이용 안내를 그림 중심으로 개편

사용자의 ‘복잡하고 직관적이지 않다’는 피드백을 반영했다. 참여자 안내를 기본으로 보여주고 생성자 안내는 선택 버튼으로 전환한다.

- 각 안내를 세 단계로 줄이고 휴대폰·영수증·검증·명부·달력·문자 발송의 SVG 삽화 6종을 직접 구성했다. 모바일에서는 그림 옆에 짧은 설명, 넓은 화면에서는 세 단계를 가로로 배치한다.
- 참여율 → 마감 후 결과, 개인 영수증 ↔ 공개 기록을 별도 도식으로 표시한다.
- 영수증 공유 주의는 항상 보이게 유지한다. 분실·비밀투표 범위·검증 한계·삭제 이의제기 설명은 접이식 질문으로 옮겼다.
- 생성자 안내는 서비스 유료 안내 문자와 휴대폰 직접 단체문자를 나란히 비교하고, 중단·재개·60일 휴지통을 짧게 표시한다.
- 외부 이미지·AI 생성 이미지·추적 스크립트 없이 벡터로 구성했다. 본문과 단계 제목이 그림 내용을 함께 설명하므로 장식 SVG는 보조기술에서 중복 읽지 않게 했다. 대상 선택 버튼에는 `aria-pressed`를 제공한다.

작업 위치 `open_vote`, `fix/vote-receipt-guidance`. 기존 변경 보존, 새 커밋·푸시 없음. DB·인증·문자 발송 로직 변경 없음.

검증: ESLint 및 Next.js 프로덕션 빌드 통과. 운영 브라우저에서 참여자/생성자 전환과 상세 펼치기를 확인했다. 상세를 펼친 뒤 대상을 바꾸면 새 안내는 모두 접힌 상태로 표시된다. 375px 너비 시험에서 두 안내 모두 가로 넘침이 없었다(문서 clientWidth/scrollWidth 모두 360px). 임시 화면 크기는 검증 후 원복했다. 실기기 시험은 하지 않았다.
