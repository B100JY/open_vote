# 그룹 수정·인원·찬반 구성 보완 (2026-10-31)

- 그룹 이름 수정의 브라우저 기본 prompt를 제거하고 화면 안의 이름 입력·저장·취소 폼으로 바꾼다. 기존 소유자 확인 POST API를 그대로 사용하며 저장 실패 시 입력을 유지한다.
- 그룹 가져오기 목록에 소속 연락처 수를 표시한다. 여러 그룹 선택 시 중복 소속은 한 번만 세고 추가 버튼에 실제 추가 대상 수를 표시한다. 추가 DB 조회·폴링은 하지 않는다.
- 단순 ‘찬성 / 반대’ 프리셋을 추가한다. 예/아니오·찬반·찬반/보류 프리셋을 고르면 ‘하나 선택’ 방식으로 맞춘다.
- ‘항목별 찬반’은 ‘안건·후보 각각 찬성/반대’로 설명을 명확히 한다. 이 방식에 ‘찬성·반대’ 같은 응답 선택지를 넣었을 때 생성 화면과 미리보기에 안내와 ‘하나 선택으로 변경’ 버튼을 표시한다.
- 기존 선거 및 실제 BallotForm·기표·집계 규칙은 변경하지 않는다. 이미 만든 선거를 다른 투표 방식으로 해석하지 않는다.

DB 스키마 변경 없음. 커밋·푸시는 하지 않는다.

검증 결과: 테스트 124개, 변경 파일 ESLint·TypeScript·프로덕션 빌드 통과. 운영 UI에서 실제 그룹명 변경 후 다시 원래 이름으로 저장하고 소속 유지도 확인했다. 그룹별 2명/2명에 중복 1명인 실제 명부에서 합계가 3명으로 표시되는 것을 확인했다. 새 찬반 프리셋은 선택지 두 개만 나타나며, 잘못된 항목별 찬반 구성도 미리보기 안의 수정 버튼으로 ‘하나 선택’으로 전환됐다. 실제 선거 생성·기표·문자 발송은 하지 않았다. 임시 시험 탭은 닫고 기존 작성 탭 두 개는 유지했다.
