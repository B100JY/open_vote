# 명부·휴대폰 단체문자·투표 휴지통

2026-10-29, `fix/vote-receipt-guidance`. 기존 미커밋 작업을 보존했고 새 커밋·푸시는 하지 않았다.

- `/contacts`: 계정별 연락처, 여러 그룹 소속, 검색·수정·삭제, 최대 500명 일괄 가져오기. 가져오기는 단일 DB 트랜잭션으로 처리한다. 전화번호가 같으면 갱신한다.
- 생성 화면에서 그룹을 선택하면 명부를 복사한다. 주소록을 수정해도 기존 선거의 고정 명부는 바뀌지 않는다.
- 단체문자는 **simply_notifier를 호출하지 않는다**. 그룹들의 합집합에서 휴대폰 번호를 중복 제거하고 30명씩 나누어 `sms:` 링크로 문자 앱을 연다. 사용자가 수신자·내용을 확인해 직접 전송한다. 모아이 포인트는 사용하지 않으며 이동통신 요금은 별도다.
- Android 등은 `?body=`로 본문 전달을 시도한다. iOS는 본문 복사·붙여넣기를 안내한다. 앱 열기 요청을 발송 완료로 표시하지 않는다. 수신자 공개·그룹 대화 여부는 문자 앱 설정 확인을 안내한다.
- 투표 관리에 휴지통·복원을 추가했다. 휴지통에서는 기표를 DB에서도 차단한다. 기존 개인 코드/링크는 삭제 예정일·삭제 이의제기 화면으로 연결한다. 자격 만료 후에도 삭제 이의를 제기할 수 있다.
- 휴지통 이동 후 60일 이상이고 이의제기가 없는 투표만 매일 한국시간 04시에 정리한다. 작업당 최대 25개다. 이의제기 1건이라도 있으면 자동 삭제하지 않는다. 사용자에게 즉시 영구 삭제·이의제기 제거 기능은 제공하지 않는다. 과금 원장은 보존한다.
- 시작일은 첫 투표 전·종료 전, 현재보다 미래이며 마감 전인 시각으로만 변경한다. 감사 선거는 원래 선언문을 교체하지 않고 `schedule` 이벤트를 추가한다. 검증기는 투표 이후의 일정 변경을 거부한다.
- 일시중단·재개는 기존 상태 전환을 이용한다. 중지해도 마감은 유지되고 종료 후 재개할 수 없다.
- 이용 안내에 단계 도식·자료 대조 도식을 추가하고 상세는 접이식으로 유지했다. 개인정보 안내의 운영자 보호 과장과 보존 기간을 바로잡았다.
- 생성자의 충전 안내가 관리자 전용 지급 페이지로 향하던 문제를 고쳐 `/credits`에서 본인 잔액·내역·충전 요청 안내를 제공한다.

## 검증

- 단위 테스트 112개, ESLint, Next 프로덕션 빌드 통과.
- 격리 PostgreSQL: 마이그레이션 두 번 적용, 시작일 변경 이력/투표 후 변경 차단, 60일 전 삭제 거부, 이의제기 보류, 복원, 보존 기간 만료된 감사 선거 전체 삭제, 다른 소유자 그룹 연결 거부.
- 실제 Next HTTP → 격리 REST → PostgreSQL → 접수 서명 → 최종 자료 검증 통과. 기존 문자 비용 예약·정산 시험도 통과.
- 실제 목록/상세 라우트의 생성자 A/B 분리·관리자 전체 조회·미인증 거부 시험 통과. 운영 `/api/contacts`, 내 선거, 삭제 Cron의 무인증 요청 401, 공개 요약 200 확인.
- 로그인된 운영 브라우저: 합성 그룹 두 개·연락처 61명 생성, 두 그룹 합집합 61명/30·30·1 분할 확인. 무료 합성 선거 생성, 시작일 변경, 시작·중단·재개, 휴지통, 만료 개인 링크의 삭제 안내·이의제기, 생성자에게 보류 표시, 복원 확인.
- 실제 문자·유료 notifier 발송은 하지 않았다. 실제 iOS/Android 문자 앱 수신자 인계와 본문 자동 입력은 실기기에서 확인하지 않았다. 60일 경과는 격리 DB에서 시험했고 운영의 실제 60일 경과·예약 실행 결과를 기다린 것은 아니다.

## 근거

- [RFC 5724 SMS URI](https://www.rfc-editor.org/rfc/rfc5724): 복수 수신자와 body 필드.
- [Apple SMS Links](https://developer.apple.com/library/archive/featuredarticles/iPhoneURLScheme_Reference/SMSLinks/SMSLinks.html): 본문을 지원한다고 보장하지 않는 공식 규격에 맞춰 복사 대안을 제공한다.
