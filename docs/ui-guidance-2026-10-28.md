# 모아이투표 안내와 가독성 개선

- 작업일: 2026-10-28. 브랜치 `fix/vote-receipt-guidance`, 새 커밋 없음.
- 기존 최신 main 통합 및 디자인 작업 트리를 유지했다. 인증·과금·투표 저장·DB 스키마는 변경하지 않았다.

## 변경

- D안 모아이 로고에서 귀 옆의 짧은 세로선만 제거했다. 공통 아이콘을 쓰는 헤더·홈에 함께 적용된다.
- 상단 메뉴를 데스크톱 13→16px, 모바일 12→15px로 키웠다.
- 공개 투표 상세 화면에는 ‘이미 투표하셨나요?’ 안내와 해당 투표의 검증 화면으로 가는 ‘이곳’ 링크를 넣었다. 개인 링크·코드 화면에서 실제 `hasVoted`가 확인된 경우에도 같은 안내를 제공한다. 종료 전후 문구를 나누고 영수증 보관을 안내한다. 공개 상세 화면에서 방문자의 투표 여부를 임의로 추정하지 않는다.
- 이용 안내를 네 가지 핵심 설명과 기본 닫힌 상세 설명으로 줄였다. 키보드로도 조작할 수 있는 기본 `details`/`summary`를 사용한다.
- 사용자 최종 의견에 따라 블록체인 용어는 사용하지 않는다. 공개 원장과 해시를 ‘투표 기록 목록’과 ‘디지털 지문’으로 설명한다. 조작 불가능을 보장하지 않으며, 자세한 설명에는 기준값도 함께 바뀌는 경우의 한계를 남겼다.
- 기존 리뷰 B-03의 영수증 공유 시 선택이 드러날 수 있다는 안내를 유지했다. 이 경고는 펼치지 않아도 표시된다.

## 검증

- ESLint 통과, 테스트 89/89 통과, Next.js 16.2.6 프로덕션 빌드·TypeScript 검사 통과.
- 로컬 `/trust` HTTP 200, 상세 설명과 펼침 버튼 각각 4개 확인.
- 검증 링크의 `election` 매개변수와 기존 검증 화면의 선거 선택 처리가 일치함을 확인했다.
- 이번 환경에서는 숨김 미리보기 브라우저를 사용할 수 없어 실제 모바일 화면·펼침 클릭을 자동 확인하지 못했다. 실제 투표 완료 개인 링크 재방문도 미검증이다.
- DB 마이그레이션·운영 DB 쓰기·문자 발송·테스트 투표·계정 생성 없음.

## 후속: 사용자 제공 이용 안내 문안

네 카드의 제목·한 줄 요약·상세 설명을 사용자 문안으로 교체했다. 기존 펼침 구조와 영수증 공유 경고는 유지한다. 정확성을 위해 ‘아무도 알 수 없다’는 제목은 ‘비밀로 지켜요’로, ‘추적 자체가 불가능’은 시간·순서 대조를 막는다는 설명으로 다듬었다. 참여 현황은 실시간 대신 주기적 갱신으로 표현하고, 영수증은 ‘암호표’ 대신 ‘확인 번호’로 설명한다. 해시는 따로 보관한 최초 기준값과 비교해야 한다는 조건과 기록·기준값이 함께 바뀌는 경우의 한계를 유지했다. 기능·DB 변경은 없다.
