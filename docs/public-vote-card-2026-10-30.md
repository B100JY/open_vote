# 공개 투표 카드 기본 정보

제목만 표시하던 제한 모드 홈 카드를 투표 카드 형태로 보완했다.

- 공개 기본 정보: 제목, 진행 중/시작 예정/종료 배지, 시작·마감 시각, 참여 대상.
- 대상은 현재 방식에 맞춰 `명부에 등록된 유권자` 또는 `명부에 등록된 회원`으로 표시한다. 개인 이름·번호·명부 내용은 공개하지 않는다. 자유 입력 대상 문구나 누구나 참여하는 기능은 추가하지 않았다.
- 상세 설명·선택 항목·결과·원장·참여율은 제한 모드에서 계속 비공개다. 카드에는 링크/코드 확인 안내를 표시하고 기존 인증 안내 화면으로 연결한다.
- 날짜는 한국 시각으로 고정하고, 기간이 길면 줄바꿈한다. 기본 공개 범위 옵션 문구도 ‘이름만’에서 ‘기본 정보’로 맞췄다.
- 기존 홈 목록 RPC의 선거별 결과에 시작 시각·인증 유형만 보완 조회한다. URL 크기와 응답 상한을 고려해 100개씩 조회하며 설명·후보를 가져오지 않는다. DB 스키마·함수 변경 없음.

검증: 단위 테스트 122개, TypeScript, ESLint, 배포 빌드 통과. 기존 실제 API 핸들러의 열람 권한 시험 통과. 운영 비인증 조회에서 기본 필드 존재·설명/후보/참여율 부재 및 결과/원장/통계/감사 API 403을 확인했다. 브라우저 535px 표시 폭에서 가로 넘침 없이 기간·대상·종료 상태가 보인다. 실제 휴대폰 기기 시험은 하지 않았다.
