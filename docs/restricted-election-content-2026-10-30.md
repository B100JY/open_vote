# 투표 내용·결과 열람 범위

## 사용 방법

- 생성 화면의 `홈에는 이름만 표시하고, 내용·결과는 투표 링크나 코드로 확인한 사람에게만 공개`는 기본 On이다.
- On이면 홈은 제목만 표시한다. 제목을 눌러도 설명·후보·득표·참여율·기간을 반환하지 않고 코드 입력을 안내한다.
- 검증된 개인 링크(`/v/...`) 또는 투표 코드 조회를 거치면 해당 선거에 한해 12시간 열람 권한을 발급한다. 이미 투표한 사람·종료 후 다시 방문한 사람도 내용·결과 링크로 이동할 수 있다. 이는 재투표 권한이 아니다.
- 이메일/회원 투표는 기존 명부에 등록된 로그인 유권자임을 확인하고 열람한다. 생성자 본인·운영 관리자는 기존 계정 권한으로 볼 수 있다.
- Off이면 기존 공개 상세·마감 후 결과 열람을 허용한다. 중간 득표 공개 제한은 유지한다.
- 기존 투표도 기본 On이며, 생성자/관리자는 `내 투표 관리 → 홈 표시·공개 범위`에서 종료 후 표시 기간과 함께 변경한다. 홈 노출 기간 기본 7일은 그대로다.

## 서버 경계

- `content_restricted`는 app_open_vote의 선거 표시 정책이다. 기표/집계 규칙이나 서명 선언문을 바꾸지 않는다. 생성 wrapper는 기존 과금·감사 생성 함수를 재사용하면서 정책 저장을 같은 트랜잭션으로 처리한다.
- 공개 목록과 상세 응답은 미확인 방문자에게 제목·식별자·제한 플래그만 반환한다. 결과·원장·통계·감사/서명 선언문/검증 묶음 API도 공통 열람 검사를 한다. 숨겨진 화면이나 다른 API 주소로 우회할 수 없게 했다.
- 열람 쿠키는 기존 코드 pepper와 분리된 HMAC 도메인을 사용한다. 선거 ID·만료 시각에 서명하고 HttpOnly·Secure(운영)·SameSite=Lax로 발급한다. 쿠키에는 코드/링크 원문, 명부 ID, 선택을 넣지 않는다. 이 쿠키만으로 기표·명부 조회·관리 작업을 할 수 없다.
- 공개 조회만으로는 열람 쿠키를 발급하지 않는다. 다른 선거의 쿠키, 변조, 만료는 거부한다. 기존 링크/코드 회전 후 이미 발급된 열람 권한은 최대 12시간 남을 수 있다.
- 공개 요약 캐시를 끄고 나머지 열람 응답은 private/no-store로 제공한다. 이미 다운로드한 자료나 타인이 공유한 결과 사본을 회수하는 기능은 아니다.

## 검증·반영

- 단위 테스트 121개, TypeScript, 전체 ESLint, 로컬·배포 빌드 통과.
- 격리 PostgreSQL: 마이그레이션 반복 적용, 기본 제한/명시적 공개, 정상·감사 생성 wrapper, 잘못된 정책 거부 및 권한 기준선 확인. 기존 기표·감사·문자 과금·연락처 시험도 통과.
- `scripts/test-election-view-access.mjs`: 실제 상세·결과·원장·통계·감사 GET 핸들러에 합성 DB/인증을 주입해 미확인 접근 차단, 다른 선거 쿠키 거부, 유효 쿠키 허용, Off 공개 경로를 확인했다.
- `scripts/test-home-policy.mjs`: 소유권·선거 ID·휴지통 제외 및 bool 옵션 저장/잘못된 입력 거부 확인.
- 운영 HTTP 비인증 조회에서 홈/목록/상세의 제목 전용 필드와 결과·원장·통계·감사 403을 확인했다. 운영 권한 기준선 위반 0건.
