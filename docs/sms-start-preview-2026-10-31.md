# 시작 전 문자 미리보기

- 문자 링크 방식 투표의 `시작` 버튼에서 기존 발송 대화상자를 연다. 미리보기 열기·형식 선택은 투표 상태 변경이나 문자 발송·과금을 하지 않는다.
- 단문 SMS와 장문 LMS의 내용 예시, 수신자 수, 단가, 예상 비용 및 포인트 잔액을 비교한다. 실제 수신자 이름·개인 링크·코드는 개별 값으로 교체된다.
- 단문 제목은 EUC-KR 36바이트(한글 18자 / ASCII 36자), 전체 본문은 90바이트까지 허용한다. 장문 제목은 30자까지다. 제목 검증 후 정규화된 값을 미리보기에 표시한다. 초과·미지원 문자 입력 시 발송을 차단하며, 서버 검증도 기존대로 유지한다.
- `문자 없이 시작`은 포인트가 부족하거나 대상이 없어도 가능하다. `시작하고 문자 발송`은 제목·대상·잔액 확인 후 시작 API 성공을 기다리고 기존 예약/발송 API를 호출한다.
- 시작과 발송 예약은 별도 트랜잭션이다. 시작 이후 발송 실패 시 시작 상태를 유지하고 이를 명시한다. 발송 응답 불명·부분 실패에 대한 기존 중복 발송 방지는 유지한다.
- 이메일 선거의 시작과 일시중지 후 재개는 기존 동작을 유지한다. 기존 전체/개별 재발송에도 같은 단문·장문 미리보기를 사용한다.

검증: TypeScript, 변경 파일 ESLint, 단위 테스트 124개, 프로덕션 빌드 통과. 실제 문자 발송 및 운영 데이터 변경은 하지 않았다.
