# 생성 전 미리보기·변경 제한 안내 (2026-10-31)

- 생성 화면 상단과 최종 생성 버튼 앞에 ‘미리보기’를 추가한다.
- ‘참여자 화면’은 실제 투표지가 쓰는 BallotForm을 재사용한다. 제목·단체명·설명·기간·선택 방식·기권·문자 인증 여부를 현재 입력대로 표시하고 항목 선택을 시험할 수 있다.
- ‘공개 안내 화면’은 설명 공개 여부와 링크/코드 열람 제한을 반영한다.
- 미리보기는 로컬 선택 상태만 사용한다. 생성·기표·OTP·문자 발송 API와 연결하지 않으며 실제 제출 버튼은 비활성화한다.
- 기본 dialog를 사용해 배경 조작·키보드 포커스를 제한한다. 닫기·Escape로 폼에 돌아오며 입력은 유지한다.
- 최종 생성 버튼 앞과 미리보기 안에 ‘생성 후에는 투표명·단체명·설명·투표 항목·방식·명부를 변경할 수 없습니다’ 안내를 표시한다. 별도로 제공하는 일정·일시중지 등 관리 기능까지 불가능하다고 안내하지 않는다.
- 새 투표 작성을 다시 시작할 때 단체명·설명 공개 선택도 초기화하도록 정리했다.

DB·권한·기표 프로토콜 변경은 없다. 커밋·푸시는 하지 않는다.

검증: 변경 컴포넌트 ESLint·TypeScript·프로덕션 빌드 통과. 운영 브라우저에서 별도 임시 탭으로 합성 입력 후 미리보기 열기, 항목 선택, 공개 화면에서 비공개 설명 제외, Escape로 닫기, 입력 유지 및 변경 제한 안내를 확인했다. 실제 생성·기표·문자 요청은 하지 않았다. 임시 탭은 닫았고 사용자가 입력 중인 원래 탭은 새로고침하거나 변경하지 않았다.
